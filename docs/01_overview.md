# 概要・目的・対象ユーザー

> 読書管理アプリ 要件定義書 — Part 1/4
> 関連ドキュメント: [非機能・機能要件](./02_requirements.md) | [データモデル・API・画面構成](./03_design.md) | [スコープ外・拡張候補](./04_scope.md)

## 1. 概要
読んだ本・読んでいる本・読みたい本を記録し、読書の進み具合や傾向を振り返るための個人向け読書管理アプリ。Vue製フロントエンドとNode.js(Hono)バックエンドで構成し、データはSQLiteに保存する。

本の登録はISBNまたはタイトルで検索して自動入力でき、手入力にも対応する。読んだページ数の記録、評価、感想、引用のメモを残し、統計や読書目標で習慣化を支援する。

## 2. 目的
- 読んだ本・読みたい本を一か所で管理し、「あの本は読んだか」「次に何を読むか」をすぐ確認できるようにする
- 日々の読書ページ数を記録し、進捗と読了までの目安を把握できるようにする
- 評価・感想・引用を残し、読んだ内容を後から振り返り・検索できるようにする
- 月別の読了数やジャンル別の傾向、読書目標の達成度で、読書習慣を可視化する

## 3. 対象ユーザー
- 個人で読書記録を付けたい利用者
- 認証・アカウント機能は持たず、単一利用者・自分のPC上での利用を前提とする(バックエンドは `127.0.0.1` のみで待ち受ける)
